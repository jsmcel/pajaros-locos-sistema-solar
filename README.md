# Pájaros Locos: Sistema Solar

Juego educativo de tirachinas: 12 misiones, 48 retos y ocho pájaros-planeta originales. Inglés sencillo, ayuda en español, voz Qwen y vídeos con imágenes WAN y modelos científicos animados.

Incluye planetas y su orden, Tierra, Sol, órbitas, Luna, fases, rotación, día y noche, traslación, eje inclinado y estaciones. Cada misión explica su contenido y lo practica jugando. Los errores ofrecen pistas; no hay vidas ni límite de tiempo.

El progreso se guarda únicamente en el navegador del dispositivo. No hay cuentas ni envío de resultados. La primera carga necesita conexión para descargar los recursos; la versión web puede funcionar después desde su caché.

## Publicación

En GitHub, abre Settings → Pages y selecciona Deploy from a branch → main → / (root). Los recursos usan rutas relativas para funcionar dentro de la carpeta del proyecto. `.nojekyll` evita procesar el juego como un sitio Jekyll.

Esta publicación contiene únicamente el juego y sus recursos. No incluye fotografías de las hojas, claves de firma, credenciales, informes de progreso ni herramientas de acceso remoto.
