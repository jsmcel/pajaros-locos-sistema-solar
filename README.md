# Pájaros Locos: Solar Adventure v2

Doce aventuras de física con pájaros clásicos, planetas como destinos, torres destructibles, huevos que rescatar, estrellas y nueve poderes, incluido Tracker Chuck. Arrastra y suelta; toca durante el vuelo para usar el poder. No hay preguntas durante la aventura, vidas ni límite de tiempo.

Learn & practise reúne todo el contenido de las dos páginas del examen de Jorge: 35 explicaciones, 48 preguntas, modelos animados, traducción opcional, narración original Qwen y 12 vídeos. Las pistas del repaso son temporales. El progreso de juego y estudio se mide por separado y se guarda únicamente en el dispositivo.

La primera carga necesita conexión para descargar recursos. Después puede funcionar desde su caché local. Tablet horizontal recomendada; también se adapta a pantallas verticales. Los datos de práctica anteriores se conservan, sin dar por superadas las nuevas aventuras.

Publicación: GitHub Pages, rama main, raíz, con .nojekyll. Esta copia solo contiene juego y recursos: no fotos del examen, claves, contraseñas ni resultados privados.

Proyecto educativo personal de fans, no oficial ni afiliado a Rovio. Angry Birds y sus personajes pertenecen a sus titulares; las ilustraciones se generaron para este proyecto, no son assets oficiales. Matter.js: licencia MIT incluida en assets. Voz Qwen3-TTS original; WAN 2.2 aporta fondos ambientales, con modelos centrales científicos dibujados mediante código.
